# Repository Guidelines

## Response Language
- Answer user questions in Chinese.

## Project Structure & Module Organization
This repository contains a Spring Boot backend in `seeklight-backend/`.
- Source code: `seeklight-backend/src/main/java/com/xshxy/seeklightbackend/` (controllers, services, mappers, config, etc.).
- Resources: `seeklight-backend/src/main/resources/` (application config, MyBatis XML in `mapper/`, static assets in `static/`, templates in `templates/`).
- Tests: `seeklight-backend/src/test/java/com/xshxy/seeklightbackend/`.
- Build output: `seeklight-backend/target/` (generated by Maven).

## Build, Test, and Development Commands
Run these from `seeklight-backend/` unless noted.
- `.\mvnw spring-boot:run` starts the local server.
- `.\mvnw clean package` builds the application JAR.
- `.\mvnw test` runs JUnit tests.
- `.\mvnw -q -DskipTests package` builds faster without tests for quick smoke checks.

## Coding Style & Naming Conventions
- Java 17, standard Spring Boot conventions.
- Indentation: 4 spaces, no tabs.
- Packages use `com.xshxy.seeklightbackend`.
- Classes: PascalCase; methods/fields: camelCase; constants: UPPER_SNAKE_CASE.
- MyBatis mapper XMLs live in `src/main/resources/mapper` and should match mapper interfaces.
- Use English for code comments and exception message strings.

## Testing Guidelines
- Framework: JUnit Jupiter via `spring-boot-starter-test`.
- Test classes follow `*Tests` naming and mirror package structure.
- Add tests for new controllers/services, especially for auth and data access paths.

## Commit & Pull Request Guidelines
Commit messages follow a Conventional Commit style with optional scopes, e.g.:
- `feat(auth): add user authentication`
- `fix: resolve console dispatch auth issue`
- `refactor(controller): normalize API endpoints`
For pull requests:
- Provide a short summary and list of changed areas.
- Include test commands run (or explain if not run).
- For API changes, include example request/response or curl snippets.

## Security & Configuration Tips
- Runtime config lives in `seeklight-backend/src/main/resources/application.yml`.
- Use local overrides or environment-specific files for credentials and secrets; avoid committing real values.
